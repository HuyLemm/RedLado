# RedLado - Game Items Trading Platform

Full-stack application for trading game items.

## Project Structure

```
RedLado/
├── frontend/      # Next.js App (React + TypeScript + Tailwind)
├── backend/        # API Server (to be implemented)
└── docs/          # Documentation
```

## Frontend

Next.js 14 application with:
- App Router
- TypeScript
- Tailwind CSS
- 42 UI Components (from Figma design system)
- Dark mode support

### Getting Started

```bash
cd frontend
npm install
npm run dev
```

## Design System

This project uses a complete design system with:
- Red brand colors (no purple tint)
- Light & Dark modes
- WCAG AA compliant
- 8pt grid system
- Semantic tokens
